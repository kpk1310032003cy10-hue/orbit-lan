# Changelog

## Unreleased

### Wake from sleep

- Windows adapter inspection and an administrator setup script with parameter backups and restore mode.
- Authenticated wake profile, subnet-aware broadcast address, setup status and downloadable phone instructions.
- iPhone/iPad setup through a native Wake-on-LAN client; an armed adapter is never reported as a completed wake test.

### Appearance

- System, light and dark themes with a header control and a settings selector.
- Device-local preference applied before styles load, live system changes and tab synchronization.
- Shared semantic colors for chat, files, quotas, forms, dialogs and notifications.
- Theme startup remains usable when browser storage is blocked.

### Mobile interface

- Calm colors, readable type, larger touch controls and task-first home screen.
- Full-screen phone conversations, viewport-aware composer and in-memory drafts across navigation.
- Stable search focus, preserved live tool disclosures and answers while messages stream.
- Compact quota summaries with expandable reset details; process cards on small screens.
- Browser coverage for 320–1440px, landscape, reduced viewport height, drafts, send and stop.

### Initial public source

- Local Windows service with HTTPS enrollment, one-time device pairing and revocation.
- Managed Codex / Claude sessions, command logs, owned task interruption and external Codex history.
- Responsive desktop, iPhone and iPad PWA with workspace files and computer metrics.
- Provider-supplied quota windows with reset times, stale-state handling and no inferred message counts.
- Native WebCrypto signing for generated certificates, preserving existing CA keys and iOS trust across updates.
- Conservative first-run workspace root, isolated tests, public-source guard and GitHub Actions checks.

No GitHub release has been published yet.
