# Roadmap

Items below are plans, not implemented features or release promises.

- A separately authenticated remote-access mode suitable for a private VPN or an identity-aware proxy, without inheriting loopback trust.
- Verification on physical iPhone and iPad hardware with Safari / standalone PWA.
- Authenticated end-to-end validation of Claude sessions and permission flows.
- Better external-session capability discovery, so unsupported controls are hidden or explained before submission.
- Optional event/history retention controls and a safer way to archive finished tasks.
- Notifications when a task needs input, with explicit support for iOS background restrictions.
- CI coverage for provider protocol fixtures and documented upgrade compatibility.
