# Начать работу с Орбитой

1. Установите **Node.js 24+** и скачайте / клонируйте репозиторий.
2. Откройте **Открыть Орбиту.cmd**. Сценарий установит зависимости при необходимости и запустит панель на **http://127.0.0.1:8787**.
3. На ПК откройте **Подключение** и выполните **Разрешить доступ по Wi-Fi.cmd**. Подтверждение Windows необходимо для добавления сетевого правила.
4. Подключите iPhone / iPad к той же Wi-Fi сети и отсканируйте QR-код в панели.
5. Установите сертификат с ПК и включите доверие по инструкции на экране. Сверьте отпечаток с панелью компьютера.
6. Нажмите **Открыть Орбиту** и введите одноразовый код. Для второго устройства используйте новый код с ПК.
7. В Safari выберите **Поделиться → На экран Домой**.

**Новая задача** создаёт сессию Codex или Claude в выбранном проекте. Кнопка **Стоп** относится к задачам из Орбиты. Существующие диалоги VS Code доступны для просмотра и продолжения отдельной веткой.

Для Claude сначала выполните **Войти в Claude.cmd** на компьютере. Новые рабочие папки подключаются в панели ПК. У новой установки по умолчанию доступна только директория самого репозитория.

**Включить автозапуск.cmd** добавляет Орбиту в автозагрузку текущего пользователя. **Остановить Орбиту.cmd** завершает процесс сервиса и его собственные задачи. Компьютер должен оставаться включённым во время удалённой работы.

Подробные инструкции: [подключение](docs/setup.md), [настройки](docs/configuration.md), [README](README.md).
