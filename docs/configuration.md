# Настройки и обслуживание

По умолчанию состояние хранится в `%LOCALAPPDATA%\OrbitLAN` на Windows. На остальных платформах без `LOCALAPPDATA` используется `~/OrbitLAN`. Исходники и каталог состояния разделены.

## Файлы состояния

- `config.json` — корни рабочих папок, сетевой IP, порты, путь Codex и фильтр процессов.
- `orbit.sqlite` и файлы WAL — устройства, задачи, события и журнал действий.
- `tls/` — корневой сертификат и его закрытый ключ, сертификат и ключ сервера.
- `backups/` — копии текстовых файлов перед изменением из панели.
- `runtime.json`, `server.log`, `error.log`, `server.lock` — запуск и диагностика.

Эти файлы не предназначены для GitHub. Копии состояния следует хранить приватно; база содержит историю задач, а `tls/ca-key.pem` позволяет выпускать сертификаты локального центра.

## Параметры `config.json`

- `name` — имя приложения.
- `httpPort` / `httpsPort` — по умолчанию 8787 / 8788.
- `lanIP` — выбранный IPv4 адрес компьютера.
- `roots` — массив `{ "id": "project", "name": "Проект", "path": "D:/Projects/example" }`.
- `codexPath` — необязательный полный путь к Codex. Без него сервис ищет бинарный файл в расширении VS Code, затем в `PATH`.
- `watchProcesses` — подстроки имён наблюдаемых процессов; по умолчанию `codex`, `claude`, `Code`, `node`, `python`.

Редактируйте конфигурацию при остановленном сервисе. Для подключения корней удобнее использовать панель ПК.

Переменные окружения: `ORBIT_STATE_DIR`, `ORBIT_HTTP_PORT`, `ORBIT_HTTPS_PORT`, `ORBIT_LAN_IP`, `ORBIT_CODEX_PATH`. Сохранённый `codexPath` имеет приоритет над переменной пути. Если задан `CODEX_HOME`, обнаружение внешних сессий использует этот каталог.

## Смена IP

Рекомендуется закрепить адрес ПК через DHCP роутера. При смене адреса:

1. Остановите сервис и исправьте `lanIP`.
2. Запустите сервис. Серверный сертификат перевыпустится для нового IP, корневой сохранится.
3. Повторно выполните `Разрешить доступ по Wi-Fi.cmd`.
4. Откройте новый адрес на телефоне. Старый ярлык PWA может потребоваться заменить.

## Автозапуск и остановка

`Включить автозапуск.cmd` создаёт ярлык `Orbit LAN.lnk` в папке автозагрузки текущего пользователя. Отключение:

```powershell
powershell -NoProfile -File scripts/uninstall-autostart.ps1
```

`Остановить Орбиту.cmd` проверяет PID и путь Node.js, затем завершает дерево процесса сервиса. Это принудительная остановка: собственные незавершённые задачи после следующего старта будут помечены как прерванные. Автоматического повторного запуска запросов модели нет.

## Обновление

Остановите сервис, сохраните нужную копию состояния, выполните `git pull --ff-only` и `npm ci`, затем запустите его снова. Обновление исходников не должно удалять каталог состояния или заменять корневой сертификат. Поддерживается чтение ранее созданных CA ключей в формате PKCS#1.

## Удаление

1. Остановите сервис и отключите автозапуск.
2. В PowerShell администратора удалите сетевое правило:

```powershell
Remove-NetFirewallRule -Name OrbitLAN-HomeWiFi
```

3. Удалите профиль Orbit LAN на iOS.
4. После сохранения нужных резервных копий удалите каталог исходников. Каталог состояния удаляется отдельно: это уничтожит историю и все сопряжения.
