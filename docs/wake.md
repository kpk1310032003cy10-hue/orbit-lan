# Пробуждение компьютера с iPhone и iPad

Орбита показывает параметры текущего сетевого адаптера в **Подключение → Пробуждение с телефона**. Windows может разрешить ему выводить компьютер из сна, если это поддерживают адаптер, драйвер и BIOS. Рабочий сценарий рассчитан на обычный сон S3 в домашней сети.

## Настройка Windows

1. Запустите Орбиту и убедитесь, что выбран правильный IP домашней сети.
2. Откройте **Включить пробуждение с телефона.cmd**. Подтвердите запрос Windows на права администратора.
3. В разделе пробуждения нажмите кнопку проверки. Сообщение «Windows разрешила пробуждение» означает, что подтверждены разрешение устройства и включённый Magic Packet. Это ещё не результат пробуждения из сна.

Сценарий выбирает физический адаптер по IP из конфигурации Орбиты. Он сохраняет прежние параметры, включает Magic Packet при необходимости и разрешает пробуждение командой `powercfg`. Адаптер и компьютер автоматически не перезапускаются. Если драйверный параметр потребовал изменения, интерфейс сообщает о необходимости перезагрузки.

Резервные копии и результат находятся вне репозитория, в `%LOCALAPPDATA%\OrbitLAN\wake-backups` и `wake-result.json`. Для восстановления прежних параметров выбранного адаптера откройте PowerShell от администратора в папке проекта:

```powershell
.\scripts\wake.ps1 -Mode Restore
```

Диагностика без изменения настроек:

```powershell
.\scripts\wake.ps1 -Mode Inspect
powercfg /devicequery wake_armed
```

## Настройка телефона

Спящий компьютер не исполняет сервер Орбиты. Для отправки Magic Packet с телефона нужен клиент Wake-on-LAN или постоянно работающий посредник в сети. Текущая реализация использует приложение телефона, без установки второго сервера.

1. Установите бесплатное [Mocha WOL](https://apps.apple.com/app/id422625778), доступное для iPhone и iPad. Разрешите доступ к локальной сети.
2. Пока компьютер включён, откройте раздел пробуждения в Орбите. Можно скопировать MAC-адрес или скачать текстовую памятку в «Файлы» телефона.
3. Добавьте профиль в Mocha WOL: укажите MAC-адрес из Орбиты, WOL Port `9`, включите **WOL on LAN** и **WOL broadcast**. Для проверки доступности используйте IP компьютера. Поле внешнего IP для работы внутри домашней сети не требуется.
4. Сохраните профиль. Затем на ПК выберите **Пуск → Питание → Сон**.
5. Отправьте команду пробуждения из приложения телефона, подключённого к той же домашней сети. После выхода ПК из сна откройте защищённую ссылку Орбиты.

Нужен MAC именно подключённого адаптера. После перехода с Wi-Fi на Ethernet обновите сетевую конфигурацию Орбиты и профиль телефона. Адрес рассылки рассчитывается по маске подсети; он не всегда заканчивается на `.255`.

## Если компьютер не проснулся

- Сначала проверьте обычное пробуждение клавиатурой или кнопкой мыши. Если оно тоже не работает, запустите **Исправить пробуждение клавиатуры и мыши.cmd** и подтвердите системный запрос администратора. Сценарий меняет только разрешения пробуждения подключённых устройств классов Keyboard и Mouse. Он выбирает конкретные устройства по PnP ID, проверяет каждое изменение и сохраняет прежние значения в `wake-backups/input-devices.json`. Сетевые настройки и BIOS при этом не меняются.
- Если Windows разрешает пробуждение, но компьютер по-прежнему реагирует только на кнопку питания, проверьте BIOS. На MSI AM5 откройте **Settings → Advanced → Wake Up Event Setup**: `Wake Up Event By` — `BIOS`, `Resume By USB Device` — `Enabled`, `Resume By PCI/PCI-E Device` — `Enabled`. На новых версиях последний пункт может называться `Resume By PCI-E/Networking Device`. В **Settings → Advanced → Power Management Setup** проверьте `ErP Ready` — `Disabled`. Сохраните изменения через F10. Орбита не перезагружает компьютер и не записывает BIOS автоматически; значения должны быть проверены в самом BIOS.
- Для проверки доставки команды запустите **Проверить сигнал с телефона.cmd**, подтвердите запрос Windows и отправьте команду из приложения, пока ПК включён. Тест принимает UDP-пакеты на порту 9 три минуты и проверяет все 16 повторов MAC-адреса. Временное правило брандмауэра ограничено программой проверки, текущим сетевым интерфейсом и локальной подсетью, а по завершении удаляется. Отчёт `wake-packet-result.json` сохраняется вне репозитория. Полученные пакеты подтверждают доставку команды при включённом ПК; питание и приём Wi-Fi во сне проверяются отдельно.
- Убедитесь, что это сон, компьютер получает питание, а телефон находится в той же сети. Гостевая сеть или изоляция Wi-Fi-клиентов может мешать доставке пакета.
- Проверьте, что нужный адаптер присутствует в `powercfg /devicequery wake_armed`.
- В BIOS MSI AM5 настройка пробуждения PCI/PCI-E описана в **Settings → Advanced → Wake Up Event Setup → Resume By PCI/PCI-E Device**. Названия и доступность зависят от версии BIOS. При необходимости включите её вручную; Орбита не изменяет BIOS.
- Wi-Fi-пробуждение дополнительно зависит от сохранения связи и питания адаптера во сне. Если оно не работает, подключите ПК кабелем к роутеру и настройте проводной адаптер.

Компьютер не переводится в сон автоматически во время установки или проверки Орбиты. Полный цикл «сон → пробуждение с телефона» выполняется отдельно. Проброс UDP-порта в интернет не настраивается.

Диагностика разрешений клавиатуры и мыши без изменений:

```powershell
.\scripts\input-wake.ps1 -Mode Inspect
```

Восстановление их прежних разрешений из резервной копии (PowerShell от администратора):

```powershell
.\scripts\input-wake.ps1 -Mode Restore
```

После изменений проверьте два отдельных цикла: **сон → клавиатура/мышь**, затем **сон → команда с телефона**. Подождите завершения перехода в сон перед каждой командой. Если пробуждение не сработало, верните ПК коротким нажатием кнопки питания и посмотрите `powercfg /lastwake`. Статус разрешения Windows и успешная доставка пакета при включённом ПК сами по себе не подтверждают исправность полного цикла.

Источники: [состояния питания Windows](https://learn.microsoft.com/en-us/windows/win32/power/system-power-states), [Magic Packet и управление адаптером](https://learn.microsoft.com/en-us/powershell/module/netadapter/set-netadapterpowermanagement), [настройка Mocha WOL](https://mochasoft.dk/wizard_wol.htm), [руководство BIOS MSI AM5, стр. 16](https://download.msi.com/archive/mnu_exe/mb/AMDAM5BIOS.pdf#page=16).
