# Установка и подключение устройств

## Требования

- Windows — основной поддерживаемый хост, Node.js 24+ и Git.
- iPhone / iPad с актуальным Safari и доступом в ту же локальную сеть.
- Для Codex: установленный CLI в `PATH` либо расширение OpenAI в VS Code; вход в аккаунт выполняется его штатным способом.
- Для Claude: вход через комплектный CLI. SDK и бинарный файл устанавливаются вместе с npm-зависимостями.

## Первый запуск

```powershell
git clone https://github.com/kpk1310032003cy10-hue/orbit-lan.git
cd orbit-lan
npm ci
npm start
```

Для запуска без открытой консоли используйте `Открыть Орбиту.cmd`. Локальная панель по умолчанию — `http://127.0.0.1:8787`. Адрес Wi-Fi компьютера определяется автоматически и показывается в разделе **Подключение**. Не копируйте чужой IP из примеров.

Выполните `Разрешить доступ по Wi-Fi.cmd` и подтвердите UAC. Правило `OrbitLAN-HomeWiFi` разрешает входящие TCP-подключения только к портам Орбиты, на выбранном IP и интерфейсе, из локальной подсети, для исполняемого файла Node.js. Оно распространяется и на профиль Windows Public; не требуется менять тип всей сети.

## Сертификат на iOS

1. На iPhone / iPad откройте QR-код с панели ПК в Safari.
2. Скачайте сертификат. Это публичная часть локального корневого центра, созданного вашим компьютером. Сверьте SHA-256 с панелью на ПК.
3. Откройте **Настройки → Основные → VPN и управление устройством**, выберите загруженный профиль и установите его.
4. Откройте **Настройки → Основные → Об этом устройстве → Доверие сертификатам** и включите доверие к Orbit LAN.
5. Вернитесь в Safari, перейдите по защищённой ссылке и введите код из панели ПК.
6. Для установки PWA нажмите **Поделиться → На экран Домой**.

Код действует пять минут, используется один раз и меняется после сопряжения. Устройство получает разрешение на 30 дней. Доступ можно отозвать в разделе **Подключение**; постоянное потоковое соединение также будет закрыто.

При удалении Орбиты удалите профиль Orbit LAN с iOS, если больше не используете этот центр сертификации.

## Рабочие папки и агенты

У новой установки доступна только папка репозитория. В панели ПК подключите нужные каталоги. На телефоне добавление новых корневых папок недоступно.

Создайте задачу, выберите провайдера и рабочую папку. Создание сессии не отправляет задачу модели; работа начинается после первого сообщения. Полное управление относится к сессиям из Орбиты. Открытый в VS Code диалог можно просматривать и продолжить отдельной веткой.

Для Claude запустите `Войти в Claude.cmd`, завершите вход и обновите статус в панели. Учётные данные не вводятся в мобильный интерфейс.

## Если устройство не подключается

- Убедитесь, что ПК включён, сервис запущен и адрес соответствует текущему Wi-Fi IP.
- Проверьте применение правила Firewall и отсутствие изоляции клиентов / гостевой сети в роутере.
- Если IP поменялся, выполните шаги из [настроек](configuration.md). Серверный сертификат будет перевыпущен для нового IP; сохранённый корневой сертификат не меняется.
- Если HTTPS открывается с предупреждением, проверьте установку профиля и отдельное включение доверия, а также время на обоих устройствах.
- После возобновления из сна перезагрузите страницу. PWA синхронизирует историю с ПК.

Прямое открытие портов в интернете и подключение внешнего reverse proxy текущая версия не настраивает. См. [модель доверия](../SECURITY.md) перед изменением сети.
